NETWORK ENGINEER ROADMAP
========================

كيفية التشغيل:
1) فك ضغط الملف.
2) افتح index.html في Chrome أو Edge.
3) استخدم القائمة للتنقل بين الصفحات.

ملاحظات:
- الموقع Static HTML/CSS/JavaScript ولا يحتاج Backend أو تثبيت.
- علامات إنجاز المهام تحفظ في Local Storage على نفس المتصفح والجهاز.
- مدد المراحل (عدا المدد الرسمية المذكورة) تقديرات مذاكرة مقترحة وليست مددًا رسمية للكورسات.
- راجع صفحات الجهات الرسمية قبل التسجيل أو حجز الامتحان.
- آخر موعد لاختبار CCNA v1.1 هو 2 فبراير 2027، ويبدأ v2.0 في 3 فبراير 2027 وفق Cisco.
