STAGE 04 / NETWORK ENGINEER PATH

Packet Tracer Practical Labs

تحويل المعلومات إلى مهارة عملية. المحاكاة لا تغني عن الأجهزة الحقيقية بالكامل لكنها ممتازة للتعلم والتدريب.

المدة: 30–60 دقيقة بعد كل موضوع CCNAالمستوى السابق: ابدأ من أساسيات Cisco واستمر خلال CCNA

هتتعلم إيه؟

  • Build topologies: PCs, switches, routers, servers
  • Basic device configuration وCLI navigation
  • VLAN creation، Access ports، Trunk ports
  • Inter-VLAN Routing باستخدام Router-on-a-Stick أو Layer 3 Switch
  • Static Routes وOSPF
  • DHCP، NAT/PAT، ACLs
  • Troubleshooting باستخدام show commands وping وsimulation mode
