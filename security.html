STAGE 07 / NETWORK ENGINEER PATH

Introduction to Network Security

تضيف منظور أمني لشغلك كـ Network Engineer، مع التركيز على تأمين الشبكات وإدارتها.

المدة: 2–3 أسابيع مقترحةالمستوى السابق: بعد أساسيات CCNA

هتتعلم إيه؟

  • Network segmentation وVLAN security concepts
  • ACL design and least privilege
  • Firewall policies وstateful inspection concepts
  • Secure management: SSH بدل Telnet، strong credentials
  • VPN concepts وsite-to-site vs remote access
  • Monitoring: Syslog, SNMP, NTP
  • مقدمة في Fortinet وNetwork Security Operations

المدة والتخطيط

المدة الرسمية / المرجعية:
خطة تطبيقية تمهيدية؛ لا تعتبر شهادة احترافية بحد ذاتها

الوقت المقترح ليك:
2–3 أسابيع مقترحة

لو بتذاكر 8–10 ساعات أسبوعيًا، وزّع الوقت بين مشاهدة المحتوى، تدوين الملاحظات، وحل الـ Labs.

معيار الانتقال

تقدر تشرح segmentation وACL وFirewall وVPN ومبادئ تأمين إدارة أجهزة الشبكة وتطبقها في Lab.

نصيحة مذاكرة

ما تكتفيش بإنك تخلص المحتوى. اقفل الشرح وحاول تعيد الفكرة أو الـ configuration من ذاكرتك، وبعدها راجع أخطاءك.
