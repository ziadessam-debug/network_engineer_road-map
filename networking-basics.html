Cisco Networking Basics

تثبيت المفاهيم من خلال منهج Cisco منظم وتطبيقات تأسيسية على الشبكات والأجهزة.

المدة: 22 ساعة رسميًا + وقت للتطبيقالمستوى السابق: بعد فهم أساسيات المرحلة الأولى

هتتعلم إيه؟

  • Networking concepts, devices, media and protocols
  • Ethernet communication وMAC addressing
  • IPv4 addressing وSubnetting basics
  • Wireless router configuration
  • إنشاء LAN بسيطة وربط الأجهزة
  • Network application services وBasic troubleshooting
