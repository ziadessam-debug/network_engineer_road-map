STAGE 03 / NETWORK ENGINEER PATH

CCNA 200-301

المرحلة المحورية في المسار. الهدف فهم وإعداد وإدارة الشبكات الصغيرة والمتوسطة والاستعداد لامتحان CCNA.

المدة: 12–16 أسبوع مذاكرة مقترحةالمستوى السابق: أساسيات Networking + Subnetting
تحديث امتحان مهم: آخر يوم لاختبار 200-301 v1.1 هو 2 فبراير 2027، وأول يوم لـ v2.0 هو 3 فبراير 2027. اختار الـ blueprint حسب تاريخ امتحانك. رسوم الامتحان الرسمية المعروضة حاليًا 300 دولار أمريكي، وقد تتغير أو تضاف ضرائب.

هتتعلم إيه؟

  • Network Fundamentals: topology, cabling, IPv4/IPv6, TCP/UDP
  • Network Access: VLANs, Trunking, STP, EtherChannel, Wireless
  • IP Connectivity: Routing Table, Static Routes, OSPF
  • IP Services: DHCP, DNS, NAT/PAT, NTP, QoS concepts
  • Security Fundamentals: ACLs, device hardening, VPN concepts
  • Automation and Programmability: APIs, controllers, JSON basics
