STAGE 01 / NETWORK ENGINEER PATH

Networking Foundations

تكوين صورة واضحة عن طريقة انتقال البيانات داخل الشبكات وفهم المصطلحات الأساسية قبل الدخول في Cisco.

المدة: 2–3 أسابيع مقترحةالمستوى السابق: مبتدئ تمامًا

هتتعلم إيه؟

  • ما هي Computer Network وأنواع LAN / WAN / WLAN
  • Network devices: Switch, Router, Access Point, Modem
  • OSI Model و TCP/IP Model والفرق بينهم
  • Ethernet، MAC Address، Frames
  • IPv4 basics، Subnet Mask، Default Gateway
  • TCP vs UDP، Ports، DNS و DHCP
  • مقدمة عن Troubleshooting: ping و tracert / traceroute

الوقت المقترح ليك:
2–3 أسابيع مقترحة

لو بتذاكر 8–10 ساعات أسبوعيًا، وزّع الوقت بين مشاهدة المحتوى، تدوين الملاحظات، وحل الـ Labs.

معيار الانتقال

تقدر تشرح OSI وTCP/IP، تفرق بين Switch وRouter، وتفهم IP وMAC وDNS وDHCP بدون حفظ أعمى.

نصيحة مذاكرة
