Linux Fundamentals for Network Engineers

تتعلم أساسيات Linux لأن أدوات الشبكات والسيرفرات والأمن بتعتمد عليه بشكل كبير.

المدة: 2–3 أسابيع مقترحةالمستوى السابق: مبادئ الشبكات واستخدام الكمبيوتر

هتتعلم إيه؟

  • Linux distributions وTerminal basics
  • Navigation: pwd, ls, cd, find
  • Files and permissions: cp, mv, chmod, chown
  • Users, groups, processes and services
  • Networking commands: ip, ping, ss, traceroute, dig, nslookup
  • SSH basics، package management، logs

المدة والتخطيط

المدة الرسمية / المرجعية:
المدة هنا خطة مذاكرة عملية وليست مدة رسمية موحدة لكورس واحد

الوقت المقترح ليك:
2–3 أسابيع مقترحة

لو بتذاكر 8–10 ساعات أسبوعيًا، وزّع الوقت بين مشاهدة المحتوى، تدوين الملاحظات، وحل الـ Labs.

معيار الانتقال

تقدر تستخدم Terminal يوميًا، تفحص إعدادات الشبكة، تدير الملفات والصلاحيات، وتفهم الخدمات والـ logs.

نصيحة مذاكرة

ما تكتفيش بإنك تخلص المحتوى. اقفل الشرح وحاول تعيد الفكرة أو الـ configuration من ذاكرتك، وبعدها راجع أخطاءك.
